# 📊 Consumer Goods Ad-Hoc Insights | SQL Resume Project Challenge #4

## 📌 Project Overview

This project is my submission for **Codebasics SQL Resume Project Challenge #4**. The objective was to solve **10 real-world business ad-hoc requests** for **AtliQ Hardwares** using SQL and present the findings in a management-friendly format with actionable insights. The challenge focuses on applying SQL to answer business questions and effectively communicate results through data storytelling. :contentReference[oaicite:0]{index=0}

## 🎯 Problem Statement

The management team at **AtliQ Hardwares** requires quick, data-driven insights to support business decisions. This project answers 10 business requests covering sales, products, customers, manufacturing costs, and channel performance using SQL. :contentReference[oaicite:1]{index=1}

## 📈 Business Requests Solved

1. Markets where AtliQ Exclusive operates in the APAC region.
2. Percentage increase in unique products (2021 vs 2020).
3. Unique product count by segment.
4. Segment with the highest product growth.
5. Highest and lowest manufacturing cost products.
6. Top 5 customers by average pre-invoice discount in India (FY2021).
7. Monthly gross sales analysis.
8. Quarter with maximum sold quantity in FY2020.
9. Gross sales contribution by sales channel.
10. Top 3 products in each division using SQL Window Functions. :contentReference[oaicite:2]{index=2}

## 📊 Key Insights

- Product portfolio increased by **36.33%** in FY2021.
- Accessories recorded the highest product growth.
- Flipkart received the highest average pre-invoice discount (30.83%).
- Retailer channel contributed over **73%** of gross sales.
- Q1 FY2020 recorded the highest sold quantity.
